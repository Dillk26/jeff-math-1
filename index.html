Algebra Cheat Sheet & Core Concepts

1 Ordered Pairs: Domain, Range & Function

  • Domain ($x$): The collection of all the first numbers (inputs). Always list from least to greatest without repeating duplicates! e.g., $\{-6, -3, 0, 7, 9\}$.
  • Range ($y$): The collection of all the second numbers (outputs). List from least to greatest without repeating duplicates!
  • Is it a function?: Look only at the $x$-values. If any $x$-value shows up more than once with a different $y$-value, it is NOT a function. If all $x$-values are distinct, it IS a function!

2 Continuous Graphs: Domain, Range & Vertical Line Test

  • Domain: How far left to how far right: $\text{[far left } x, \text{far right } x]$.
  • Range: How far down to how far up: $[\text{lowest } y, \text{highest } y]$.
  • Brackets vs Parentheses:
    $\circ$ (Open circle) $\implies$ use parentheses () (value is NOT included).
    $\blacksquare$ or $\bullet$ (Closed dot/square or solid curve) $\implies$ use square brackets [] (value IS included).
  • Vertical Line Test: If any vertical line passes through more than one point on the graph at the same time, it FAILS and is NOT a function.

3 Function Notation, Operations & Compositions

  • $f(n) = 2n - 2$ means replace the variable with the number in parentheses: $f(-5) = 2(-5) - 2 = -12$.
  • Absolute Value $|a|$: Turns negative results positive: $|-8| = 8$. Always evaluate what's inside the bars before multiplying by outside coefficients!
  • Sum of Functions: $g(4) + h(4)$ means calculate $g(4)$ first, then calculate $h(4)$, then add the two results together!
  • Composition $g(h(3))$: Always work from the inside out! First find $h(3) = \text{result}$. Then plug that result into $g(\text{result})$.
